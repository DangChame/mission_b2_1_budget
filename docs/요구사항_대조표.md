## 4. 기능 요구 사항

### 1) 실행 및 입력 방식

| 요구 | 충족 | 위치 |
|---|:--:|---|
| `python -m budget_app <command> [options]` | ✅ | `budget_app/__main__.py` |
| 모든 명령이 `--help` 지원 | ✅ | `cli.py build_parser()` — argparse 가 자동 생성 |
| 입력 기본 방식은 대화형 | ✅ | `cmd_add` 가 `prompts.ask` 로 순차 질문 |
| search/list/summary/export/import/delete 는 옵션 방식 | ✅ | `cli.py` 각 서브파서 |
| update 는 한 방식으로 문서에 고정 | ✅ | **안 A(옵션 기반)** — README 「update 방식」 |
| 옵션 표기는 `--` 로 통일 | ✅ | 전 옵션 `--` 사용 |

### 2) 데이터 모델

| 요구 | 충족 | 위치 |
|---|:--:|---|
| id / type / date / amount / category / memo / tags | ✅ | `models.Transaction` |
| dataclass 또는 준하는 구조 | ✅ | `@dataclass` 4개 |
| 클래스 최소 2개 이상 | ✅ | `Transaction` `Category` `Budget` `RecurringRule` `Repository` `BudgetService` = **6개** |
| 날짜 형식 오류 처리 | ✅ | `models.is_valid_date` — 정규식 + 실제 달력 확인 |
| 음수/0 금액 처리 | ✅ | `service.validate_amount` |
| 허용되지 않은 type 처리 | ✅ | `service.validate_type` |
| 존재하지 않는 category 처리 | ✅ | `service.validate_category` |
| 재입력 요구 또는 오류 메시지 | ✅ | `prompts.ask` — **틀린 항목만 재입력**(최대 3회) |

### 3) 저장 정책

| 요구 | 충족 | 위치 |
|---|:--:|---|
| JSONL 또는 CSV 중 1개 | ✅ | **JSONL** 선택 (이유는 README) |
| 저장 파일 3개 이상 분리 | ✅ | transactions / categories / budgets / **recurring** = 4개 |
| 기본 저장 폴더 `./data` | ✅ | `cli.py` `--data-dir` 기본값 |
| 옵션으로 폴더 변경 | ✅ | `--data-dir` |
| 파일 없으면 자동 생성 | ✅ | `repository.ensure_ready()` |
| 카테고리 비면 기본 생성 또는 안내 | ✅ | **안 A** — 기본 5개(food/transport/rent/salary/etc) 자동 생성 |

### 4) add

| 요구 | 충족 | 위치 |
|---|:--:|---|
| 대화형으로 필드 입력 | ✅ | `cmd_add` |
| category 가 등록 목록에 있어야 함 | ✅ | `validate_category` — 없으면 재입력 유도 |
| 생성된 id 출력 | ✅ | `[저장 완료] id=TX-000001` |

### 5) list

| 요구 | 충족 | 위치 |
|---|:--:|---|
| 최신순 출력 | ✅ | `service._newest_first` — 날짜↓, 같으면 id↓ |
| `--limit N` 지원 (기본값 제공) | ✅ | 기본 20 |
| **제너레이터 기반 스트리밍** | ✅ | `repository.iter_raw` (`yield`) + `heapq.nlargest` |

> 정렬 때문에 `sorted()` 를 쓰면 전체가 메모리에 올라간다.
> `heapq.nlargest` 는 크기 N 힙만 들고 한 번 훑는다. **실측 183KB vs 27.2MB.**

### 6) update / delete

| 요구 | 충족 | 위치 |
|---|:--:|---|
| `delete --id <id>` | ✅ | `cmd_delete` |
| 없는 id 는 "없는 데이터" 메시지 | ✅ | `service.get_transaction` → `NotFoundError` |
| update 방식 문서에 고정 | ✅ | **안 A(옵션 기반)** |
| 전체 재작성 / 임시 파일 / **원자적 교체** | ✅ | `repository.rewrite` — `.tmp` → `os.replace` |

### 8) summary

### 11) import / export

| 요구 | 충족 | 위치 |
|---|:--:|---|
| `import --from <file>` 일괄 등록 | ✅ | `service.import_csv` |
| `export --out <file>` | ✅ | `service.export_csv` |
| export 는 `--month` 또는 `--from/--to` 필수 | ✅ | 없으면 `ValidationError` |
| CSV 스키마 고정 (date/type/category/amount/memo/tags) | ✅ | `service.CSV_COLUMNS` |
| UTF-8, 머리글 포함 | ✅ | `encoding="utf-8"`, `writeheader()` |

> import 는 **잘못된 줄만 건너뛰고** 나머지는 넣는다. 몇 번째 줄이 왜 걸렸는지 알려준다.

## 7. 제약 사항

| 제약 | 지켰나 | 확인 방법 |
|---|:--:|---|
| 표준 라이브러리만 | ✅ | `import` 목록에 서드파티 없음 (아래 명령으로 확인 가능) |
| `pip install` 불필요 | ✅ | `requirements.txt` 가 없다 |
| JSONL 또는 CSV 중 1개 | ✅ | JSONL |
| 저장 파일 3개 이상 | ✅ | 4개 |
| 옵션 표기 `--` 통일 | ✅ | 단일 대시 옵션 없음 |
| 스택트레이스 출력 금지 | ✅ | `TestCliExitCode.test_스택트레이스가_노출되지_않는다` |
| 오류 종료 코드 ≠ 0 | ✅ | `TestCliExitCode.test_오류는_0이_아니다` |
| Python 3.10 이상 | ✅ | `X | Y` 문법, `match` 미사용 |

```bash
# 외부 라이브러리를 쓰지 않았는지 직접 확인
grep -rhoE '^(import|from) [a-zA-Z_]+' budget_app/ | sort -u
```
